# TG Directory Bot 2.0

一个面向 Ubuntu 服务器的 Telegram 网址收录与运营系统。项目包含独立 Telegram 机器人、中文 Web 管理后台、SQLite 数据库、定时备份和恢复工具。

本项目是通用、合规的网址目录模板。默认禁止词会拦截博彩相关内容；请遵守 Telegram 规则及用户所在地法律。

## 已实现

- 图标分类菜单：搜索服务、提交搜录、群组管理、管理员、联系超级管理员和帮助教程；支持 `v8搜录 内容` 及图片、视频、音频和文件搜录。
- 地址必须由超级管理员审核；超级管理员可修改、下架收录，并添加或删除机器人管理员。
- 超级管理员私密笔记：私聊发送 `1 关键词 内容` 保存，发送 `2 关键词` 查询最近 5 条；支持文字和文件，单关键词最多 99 条，保留 9 个月。
- Telegram 内联审核，审核结果自动通知提交用户。
- 双向客服：用户主动点击“联系超级管理员”后发消息，管理员可在 Telegram 用 `/reply` 或 Web 后台回复，双方消息不自动撤回。
- 未收录提示可在后台修改，默认提示“地址没有收录，请联系管理员”。
- 关键词自动回复：支持包含/完全匹配、私聊/群组作用域、规则启停、命中统计和后台管理；普通私聊未命中不会自动转客服。
- 群关键词动态查询：默认发送 `888地址` 会搜索“888”的已通过收录，发送 `z0` 会显示精简的 OKX P2P 前 10 商户报价、抓取时间和提醒；触发词可在后台修改。
- Web 后台：仪表盘、收录审核/编辑、用户禁用、客服、群发、举报、设置、审计。
- 波场地址校验，查询 TRX、TRC20-USDT、注册时间和最近交易；可监控 TRX/USDT 新转账及余额阈值，并为每个监控设置提醒消息 0-30 天后撤回。
- /rate 展示 OKX P2P USDT/CNY 前 10 条商户广告报价，可切换买卖方向和银行卡、微信、支付宝。
- 群抽奖：按分钟、指定北京时间、快速 10 分钟、单档/多档奖品、按钮参加、中奖率、逐人奖品、自动开奖、手动开奖/取消和抽奖记录；发送“抽奖”列出全部进行中活动，参与人数可由群管理员显示或隐藏。
- 群广告：群管理员可设置定时广告间隔、图片/视频/文件与文字，以及机器人所有群消息的前置或后置广告。
- 群积分：支持签到、增减、清零、礼品兑换；积分排行最多 100 名、每页 10 名且姓名可点击，并提供账单、中奖和兑换记录。
- 积分抽奖：礼品直接使用积分礼品；群员可设置本次消耗，概率按“本次消耗积分 ÷ 礼品积分”换算，0.1-5 倍倍率和抽奖开关仅超级管理员可见可改。
- 快捷发布：群管理员可保存文字、媒体和链接按钮，直接发布或使用机器人 inline 代码分享。
- 个人邀请链接：群内 `/link` 生成个人链接；一个成员只在第一次进群时计入邀请，退群换链接重进不重复计算；超级管理员可设置每位有效邀请奖励积分。
- 群活跃抽奖：可从发布后或近 31 天内指定日期统计发言，支持达到次数后随机抽取或按发言排行开奖。
- 进群欢迎与验证：群管理员可设置欢迎语并开启点击验证；开启后新成员验证前无法发言。
- 所有机器人普通消息默认 180 秒后自动撤回；自动开奖播报、抽奖公告和抽奖结果永久保留。
- 群统计仅群管理员可用；活跃排行只显示发言次数和名次。成员发言明细仅保留 31 天，不保存普通聊天正文。
- 群监控：机器人/后台心跳、待发与失败消息、群活跃，以及管理员独立维护的违规关键词和链接处罚。
- 搜索统计：独立记录搜索量、搜索用户和“谁搜索了什么”，Telegram 入口仅超级管理员可见。
- 开奖查询：双色球、福彩3D、七乐彩、快乐8、大乐透、排列3、排列5、7星彩、香港六合彩、澳门六合彩和新澳六合彩。
- 群开奖播报：群管理员通过按钮总开关或逐彩种勾选；新期号去重播报，重启不补播旧结果。
- 历史开奖：发送“快乐8历史”等彩种关键词，分页查看最近 100 期；也支持 `/lotteryhistory 快乐8`。
- SQLite WAL 并发、重复网址保护、禁止词过滤、CSRF 防护、签名会话。
- 后台一键创建/下载备份，systemd 每 6 小时自动备份，SHA-256 校验恢复。
- Ubuntu systemd 双服务和可选 Docker Compose。

~~~text

/search 关键词      搜索
/my                 我的提交
/contact 内容       联系客服
/report 编号 原因   举报
/balance 波场地址   查询余额、注册时间和最近1笔交易；也可直接发送地址
~~~

富媒体搜录：发送 `v8搜录 文字或地址`；图片、视频、音频或文件则把同样格式写在媒体说明里。所有人可提交，超级管理员审核后才生效。旧的“收录”写法继续兼容。

群历史开奖关键词还包括：`香港六合彩历史`、`澳门六合彩历史`、`新澳六合彩历史`。每页显示 10 期，本地最多保留 100 期。

## 快速开始

Ubuntu 服务器请直接阅读 UBUNTU_CN.md。

~~~bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
python run_web.py
~~~

后台默认地址是 http://127.0.0.1:8080。

后台“自动回复”页面可创建关键词规则并选择私聊、群组或全部；“系统设置”可修改未收录提示、转人工确认语、群地址检索后缀和实时汇率关键词，并维护独立的群违规关键词。

机器人主菜单按功能归类。普通用户看到“搜索服务、提交收录、群组管理、联系超级管理员、帮助教程”；管理员额外看到“管理员”；只有超级管理员的“搜索服务”子菜单会出现“搜索统计”。只有点击“联系超级管理员”或发送 `/contact` 后才进入不自动撤回的双向客服。

机器人加入群后，在 BotFather 使用 `/setprivacy` 关闭 Privacy Mode，才能统计普通群消息。若启用群违规处罚，还需将机器人设为群管理员并授予“删除消息”和“封禁用户”权限；该开关默认关闭。

所有用户都可在私聊或群内发送 `关键词搜录 内容`，例如 `v8搜录 t.me/example`。内容可以是文字、网址、图片、视频、音频或文件；媒体搜录需把该格式写在说明中。提交进入待审核状态，只有超级管理员可以通过、修改或删除；提交原消息在确认后才撤回。旧的 `关键词 地址` 和“收录”写法继续兼容。

群管理员从“群组管理”进入开奖订阅、抽奖方案和广告管理。开奖订阅提供全部总开关和每个彩种的 ✅/❌ 开关；定时广告支持 `间隔分钟 | 文字` 和带说明的媒体。消息前/后广告只使用文字，并合并到机器人同一条消息中，不再另外发送两条。

群积分入口也在“群组管理”。群员发送 `签到`、`积分`、`积分排行`、`积分礼品`、`兑换 礼品编号` 使用积分功能。所有成员可查看今日和近 7 天活跃排行；近 31 天活跃数据与群综合统计仅超级管理员或相应管理员可查看。

普通机器人回复以及用户发给机器人的原消息默认在 180 秒后删除，私聊同样执行；群内删除用户原消息需要机器人具备删除消息权限。开奖自动播报、抽奖创建消息和开奖结果不自动删除。所有界面、机器人回复、日志、备份文件名和备份计划均使用北京时间（UTC+8）。

群内普通聊天不自动删除。正常触发机器人功能的成员消息在 180 秒后清理；开启违规处罚后，包含链接或命中管理员独立维护的违规关键词的消息立即删除，第 1-4 次累计违规禁言 3 天，第 5 次踢出群组。管理员可通过“管理员 > 违规词管理”、`/badword add|del|list` 或 Web 后台维护词库；搜索关键词不会自动成为违规词。只有超级管理员或后台主账号可以开启、关闭处罚。

系统记录 `/search 关键词`、菜单搜索和群内 `关键词地址` 的搜索事件。搜索统计按钮只对超级管理员显示，也可由超级管理员私聊发送 `/searchstats` 查看；后台“搜索统计”页面显示关键词搜索量、搜索用户和“谁搜索了什么”的完整分页数据。

## 数据源说明

- 波场账户与交易接口：默认依次使用 TronGrid、TronScan 和 TronScan 兼容接口；填写 `OKLINK_API_KEY`、`TOKENVIEW_API_KEY` 后会继续自动切换 OKLink、Tokenview。生产环境建议同时填写 `TRONGRID_API_KEY`。
- OKX 报价榜：OKX P2P 页面使用的公开预登录市场接口。它不属于 OKX V5 正式开放 API，字段或可用性可能变化，系统已加入超时、错误提示和 30 秒缓存。
- OKX P2P 数据是商户广告报价，不是法定汇率，也不保证可按展示价格成交。
- CoinGecko 仅在 OKX 榜单不可用时提供备用参考中间价。
- 福彩结果优先使用实时开奖接口并保留官方/公开缓存兜底，体彩同样使用实时接口与官方/公开缓存，香港六合彩来自香港赛马会官方接口；到开奖时间后每 10 秒检查一次，取得新期号后停止并等待下期。
- 澳门六合彩和新澳六合彩没有澳门政府认可的官方开奖源，不能当作官方结果。澳门六合彩使用第三方 Marksix6；新澳六合彩使用 `macaujc.com` 公布的最新与年度历史接口。三种六合彩统一显示红/蓝/绿波色和开奖年份生肖，本地最多保留 100 期。
- 福彩接口会先访问对应历史开奖页面获取会话 cookie，再分页读取 JSON 历史记录，降低 403 拦截概率。
- 官方接口被 403/WAF 拦截时，会自动读取公开 GitHub `public_data/draws/{彩种}.json` 备用源，保证历史开奖有可用缓存。
- 官方站点带有访问安全策略。接口失败时系统会记录错误并保留数据库内最近一次已验证结果，不会把错误页面解析成开奖结果。
- 历史开奖按每页 10 期显示，翻页读取本地最近 100 期缓存，不会重复请求官方接口。
